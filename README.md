# Kreditrisikoanalyse und Frühwarnsystem – Schwarzwald Kreditkasse AG

IHK-Abschlussprojekt im Rahmen der Weiterbildung Data Analytics & Data Science (Masterschool, 2026)

## Ziel
Kredite mit hohem Ausfallrisiko frühzeitig erkennen, damit die Bank rechtzeitig handeln kann.

## Daten
Analyse von 11.028 Kreditanträgen.

## Vorgehen
1. Datenbereinigung und explorative Datenanalyse (EDA)
2. Entwicklung eines Machine-Learning-Modells zur Risikovorhersage
3. Bewertung des Modells mit Fokus auf hohe Trefferquote (Recall), damit möglichst wenige Risikokredite übersehen werden
4. Darstellung der Ergebnisse in einem Dashboard

## Ergebnis
IHK-Prüfung erfolgreich bestanden.

## Tools
Python, Pandas, Scikit-learn, Tableau
